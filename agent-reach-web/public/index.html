🔵 LinkedIn Headless Auth (Profile Sync)

Since this dashboard runs on a headless server, you must generate the LinkedIn login profile on your local Windows PC.
1. Open Windows PowerShell and run: uvx mcp-server-linkedin@latest --login
2. A browser will open. Log into LinkedIn.
3. Go to C:\Users\YourName\.linkedin-mcp\ and ZIP the profile folder.
4. Upload that ZIP file here to sync your session.
